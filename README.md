# GAIP AI 对话 · 独立移动 H5

本地交互样板。只包含 AI 对话、方案选择、历史会话、附件选择和语音交互，不包含登录、官网入口、客户选择或其他业务频道。

## 运行

在本目录执行 `npm start`，访问 `http://127.0.0.1:4173`。运行时为原生 HTML/CSS/ES Modules，无需安装前端依赖；需要 Python 3 提供静态服务。不能以双击 `file://` 代替 HTTP 模块加载。

测试执行 `npm ci` 后 `npm test`。Node.js 24 已验证；开发依赖只服务于测试、图标来源和格式整理，不被页面加载。

## 体验路径

1. 点击“做方案”，选择方案后直接补充需求。不存在客户选择或客户 ID 前置条件。
2. 输入“对比三份方案”，查看五列对比表：局部横向和纵向滚动、固定首列、全屏查看。
3. 发送后可以停止生成、重新生成；历史会话保留草稿和所选方案。每条历史右侧“…”支持编辑名称、确认删除；取消不改变原数据。
4. 直接按住输入框麦克风开始，反馈层自动出现；松开转文字，上移超过 72px 后松开取消，移回可继续。无需先打开面板。
5. 默认采用语音演示，不使用麦克风，回填明确标注的示例文字。顶栏不显示模式开关；开发验收真实麦克风可使用 `?voice=live`。短按不足 600ms 不产生转写。
6. 真实采集需要授权；等待授权时已松开，迟到的音频流立即释放，需要重新按住。
7. 最多 60 秒；页面切后台或手势被系统打断时取消。真实 ASR 尚未接入，采集结束明确提示，不生成假转写。
8. 演示转换完成自动回填输入框，无二次确认面板；用户可以修改后手动发送。
9. 每次打开默认显示新会话，已有消息、草稿和方案保留在历史中；不会反复创建空白记录。

## 当前能力边界

- 对话和方案回复均由本地模拟适配器提供，不调用真实 AI 或业务服务。
- 历史记录只保存在当前浏览器专用 localStorage 键 `gaip-mobile-chat-v1`；不跨端同步。
- 附件只保存名称、大小和类型用于交互展示，不读取文件正文，不上传或解析。单条最多 5 个，单个不超过 20 MB。
- 语音采集仅在内存中处理，结束或取消即停止麦克风，不上传、不持久保存。没有 ASR 后端调用。
- 手机软键盘与安全区已有布局处理，但浏览器尺寸测试不能替代 iOS/Android/企业微信真机验证。
- 移动端使用系统中文字体，避免每次加载来源 Web 的两份约 8 MB 字体文件。图标和配色沿用来源基础；仅麦克风补充图标来自 Lucide，许可证见 `assets/LUCIDE-LICENSE`。

## 维护结构

- `src/app.js`：消息渲染、页面交互、弹层与输入框。
- `src/styles.css`：只作用于本项目的移动布局与视觉。
- `src/data.js`：方案元数据和演示场景。方案保留来源 ID 与原始名称，移动端使用简化展示名称。
- `src/service.js`：异步流式服务适配器，替换真实接口的边界。
- `src/store.js`：会话持久化、编辑/删除及附件约束。
- `src/history.js`：历史管理菜单、名称校验与删除确认。
- `src/voice.js`：录音状态、实时音量、手势及资源释放。
- `tests/`：数据与取消流程、存储恢复、语音流程及麦克风资源释放测试。
- `docs/`：来源检查、接口观察和验收记录。

独立运行时不引用 `../样式优化html`，不加载全站 Umi、不依赖其 Ant 弹窗、Mock 脚本或 DOM 类名。Web 与 H5 的视觉分别维护；后续可共用后端接口。当前未抽取会影响 Web 的共享包。

## 过程与滚动

- `src/process.js` 渲染服务提供的公开步骤摘要；有过程数据才出现推理面板，有技能调用事件才出现技能标题。普通对话不显示技能头。
- 推理过程演示支持展开、收起、阶段状态和中断恢复；真实服务尚未接入。
- 发送和新内容到达时持续滚到正文底部；用户主动上滑或展开过程时暂停，点击“回到最新消息”恢复。
- 操作反馈使用居中黑底白字 Toast；复制为右侧纯图标。
