# 触摸后的焦点描边修复（v23）

全局 `:focus-visible` 曾无条件添加灰色描边。手机浏览器在打开弹窗、自动聚焦输入框或关闭弹窗恢复焦点时，也可能匹配该状态，导致关闭按钮、文件卡片和历史菜单出现额外轮廓。

现在根据实际操作方式显示焦点反馈：触摸、鼠标点击不添加额外轮廓，Tab 等键盘导航保留提示。不会调用 blur，不影响输入框焦点、软键盘或弹窗焦点恢复；卡片和输入框本身的边框保持不变。

验证：25 项自动测试通过；浏览器验证了 Tab 提示、历史侧栏关闭按钮、会话管理关闭按钮、编辑名称输入框、关闭后菜单按钮、PDF 预览返回按钮及返回后文件卡片。触摸事件和程序恢复焦点由回归测试覆盖。未在真实 iPhone / 企业微信设备上运行测试，需用更新后的线上页面复核。
