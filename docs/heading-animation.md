# 欢迎页渐变文字动画

- 原独立 SVG 每 12 秒移动 4 秒、停留 8 秒，容易被误认为静态。
- H5 改为原配色的 CSS 文字渐变，6 秒连续循环，保留 144px 文字宽度及原间距；使用 WebKit 文字裁剪兼容声明。
- 不支持文字裁剪时回退青色文字；系统减少动态效果时显示静态渐变。
- index.html 的样式和入口模块缓存版本更新为 v11。
- Chromium 手机模拟 390px：间隔 1.2 秒的背景位置及实际截图均变化；320px 无页面横向溢出；减少动态效果下 animation 为 none；无页面脚本错误。
- 当前 macOS 环境不支持安装此版本 Playwright WebKit，未进行 Safari 或 iPhone 真机验证。
- Web 源项目未修改。
