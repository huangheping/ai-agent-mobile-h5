# 欢迎页渐变文字动画

- H5 使用原配色的 CSS 文字渐变，保留 144px 文字宽度及原间距；使用 WebKit 文字裁剪兼容声明。
- 对照原 SVG 修正 v12 色带及行程缩短的问题：单条完整色带为文字宽度的 2 倍（原色标 0/18/38/60/78/100%），从 -1.5 倍文字宽度移动到 +0.5 倍，向右完整移动一条色带后才停留。播放 4 秒、末帧保持 4 秒，再循环（本次用户调整）。
- 不支持文字裁剪时回退青色文字；系统减少动态效果时显示静态渐变。
- index.html 的样式缓存版本更新为 v22；8 秒循环中，0–50% 完整播放，50–100% 保持末帧。
- Chromium 手机模拟 390px：核验 0、1、2、3、4、6、11、12、14 秒动画位置及完整 288px 行程；播放中截图变化，4 秒末帧与 11 秒截图完全一致，确认完整播放后停留和再次启动。此前已验证 320px 无横向溢出、减少动态效果下 animation 为 none。
- 当前 macOS 环境不支持安装此版本 Playwright WebKit，未进行 Safari 或 iPhone 真机验证。
- Web 源项目未修改。
