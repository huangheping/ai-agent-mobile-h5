# 欢迎页渐变文字动画

- H5 使用原配色的 CSS 文字渐变，保留 144px 文字宽度及原间距；使用 WebKit 文字裁剪兼容声明。
- 与原 SVG 的方向和节奏对齐：颜色从左向右流动 4 秒，停留 8 秒，再循环。两段重复渐变使循环复位无跳色。
- 不支持文字裁剪时回退青色文字；系统减少动态效果时显示静态渐变。
- index.html 的样式和入口模块缓存版本更新为 v12。
- Chromium 手机模拟 390px：核验 0、2、4、6、11、12、14 秒动画位置；5 秒与 10 秒的截图完全一致，确认停留和再次启动。此前已验证 320px 无横向溢出、减少动态效果下 animation 为 none。
- 当前 macOS 环境不支持安装此版本 Playwright WebKit，未进行 Safari 或 iPhone 真机验证。
- Web 源项目未修改。
