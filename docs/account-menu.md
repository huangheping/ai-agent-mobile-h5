# 历史抽屉底部账号菜单

- 用固定的头像/姓名入口替换原抽屉底部演示保存说明，点击后向上展开账号卡片；历史列表独立滚动。
- 卡片包含头像、姓名、添加到桌面、域账号、团队、版本和退出登录入口。姓名/域账号/团队使用用户参考图的示例资料，并明确标注演示账号；版本使用当前 package.json 的 0.1.0。
- 无真实登录服务；退出入口显示说明，不清除会话或伪造退出结果。
- 添加到桌面提供 Safari、安卓、微信/企业微信、电脑环境的对应操作指引及复制链接。当前未配置完整 PWA 安装清单；仅在浏览器确实发出 beforeinstallprompt 时调起原生安装确认。独立模式和本次已收到安装事件时隐藏入口，不声称跨浏览器检测安装。
- 点击外部关闭小菜单；Escape 先关闭小菜单，再关闭历史抽屉；关闭抽屉后菜单状态复位。小屏菜单限制高度、内部可滚动，支持减少动态效果。
- Chromium 手机模拟 390px、320×568 通过：菜单不越界、列表滚动时账号位置固定、Escape/外部关闭、安装指引切换、演示退出说明、安装事件后重新打开仍隐藏安装入口。24 项自动测试通过。未进行手机真机验证。
- 新增的桌面添加/退出图标来自项目现有 Lucide 依赖，许可证保留在 assets/LUCIDE-LICENSE。复用主色 #2F3640、品牌青绿 #005D56。
- H5 资源缓存版本 v15；所有更改仅在独立 H5 项目，Web 源项目未修改。
