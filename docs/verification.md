## H5 技术依据

- Pointer Events 的指针捕获可在手指离开原按钮后继续接收移动和结束事件；配合按钮局部 `touch-action: none` 处理上移取消，其他页面区域仍可滚动。参考 [MDN Pointer Events](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events)。
- 真实语音输入需要麦克风权限和安全上下文，正式环境应使用 HTTPS。参考 [MDN getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)。
