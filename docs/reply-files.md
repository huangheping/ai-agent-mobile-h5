# AI 回复文件演示

仅修改独立 H5 项目；文件演示和后续视觉调整按用户要求统一同步 GitHub。

发送“查看演示文件”（或包含 PDF / Word / Excel 的消息），回复会带出三张文件卡片。选择方案后的演示回复也提供三种文件；方案对比回复提供 Excel 文件。

- PDF：实际 DOCX 转出的 PDF，预览使用由同一 PDF 渲染的分页图片，可放大与恢复适合宽度。
- Word：真实 DOCX 文件；手机正文预览从保存后的文件提取段落，提供重新排版后的阅读视图，不声称复刻 Word 页眉、页脚和分页。
- Excel：真实 XLSX 文件，与预览共用演示数据。两张工作表可切换，表头与第一列固定，宽表独立滚动。
- 下载：同源文件链接，保留原文件扩展名。具体保存菜单由手机浏览器或宿主应用决定。
- 文件标识保存在消息中，重新进入历史会话仍可打开。仅允许已定义的本地演示文件，不把消息中的 URL 或 HTML 作为预览来源。
- 预览失败提供重试和下载；关闭时中止加载并返回原卡片，不改变对话滚动位置。

预览是这三份演示附件的配套内容，尚不是任意上传文件的通用解析器。未接入第三方 Office 预览服务，也不会上传文件。

验证：390px 和 320px 宽度下三种预览、PDF 缩放、Excel 工作表切换与横向滚动、三种原文件下载、历史会话恢复通过；原有 24 项测试通过。使用桌面 Chromium 模拟手机尺寸，未替代 iPhone / 微信真机验证。

生成脚本与源数据在 `tools/demo-assets/`，使用 Codex 提供的文档运行库；文件与配套预览在 `demo-files/`。中文 PDF 渲染需要将 `FONTCONFIG_FILE` 指向该目录的 `fonts.conf`。

后续视觉调整：文件卡片使用用户提供的 PDF、Word、Excel SVG，32px 原色显示；已选方案条使用推荐问题卡片相同的 1px 渐变描边，保留淡灰底色；欢迎文字完整播放 4 秒后停顿 4 秒。
